# ແອັບ ການເງິນໂຄງການ — ຄູ່ມືຕິດຕັ້ງ (PWA → APK)

ແອັບນີ້ເກັບຂໍ້ມູນ ແລະ ຮູບ ໄວ້ **ໃນໂທລະສັບເອງ**. ໃຊ້ບໍ່ມີອິນເຕີເນັດໄດ້ ແລະ ບໍ່ຕ້ອງລັອກອິນ.

## ໄຟລ໌ໃນແພັກເກັດ

| ໄຟລ໌ / ໂຟນເດີ | ໜ້າທີ່ |
|---|---|
| `index.html` | ຕົວແອັບທັງໝົດ |
| `manifest.webmanifest` | ຊື່ແອັບ, ໄອຄອນ, ສີ (ເຮັດໃຫ້ຕິດຕັ້ງເປັນແອັບໄດ້) |
| `sw.js` | ເຮັດໃຫ້ໃຊ້ບໍ່ມີເນັດໄດ້ |
| `icons/` | ໄອຄອນແອັບ |
| `fonts/` | ຟອນລາວ (Noto Sans Lao) |
| `vendor/` | ຕົວອ່ານ/ສ້າງ Excel (ໃຊ້ໄດ້ offline) |
| `.nojekyll` | ໄຟລ໌ເປົ່າ, ຈຳເປັນສຳລັບ GitHub Pages |

---

## ຂັ້ນທີ 1 — ເອົາແອັບຂຶ້ນເວັບ (ຟຣີ) ດ້ວຍ GitHub Pages

ແອັບຕ້ອງຢູ່ເທິງເວັບທີ່ເປັນ **https** ຈຶ່ງຈະຕິດຕັ້ງໄດ້.

1. ສະໝັກບັນຊີຟຣີທີ່ **github.com**. ຊື່ຜູ້ໃຊ້ (username) ຈະກາຍເປັນທີ່ຢູ່ເວັບ.
2. ກົດ **New repository**. ຕັ້ງຊື່ repo ເປັນ **`USERNAME.github.io`** ໂດຍປ່ຽນ `USERNAME` ເປັນຊື່ຜູ້ໃຊ້ຂອງເຈົ້າ. ເລືອກ **Public** ແລ້ວກົດ Create.
   > ຕ້ອງໃຊ້ຊື່ນີ້ແທ້ໆ ເພື່ອໃຫ້ຂັ້ນທີ 3 (ເອົາແຖບທີ່ຢູ່ເວັບອອກຈາກແອັບ) ເຮັດວຽກ.
3. ໃນ repo ກົດ **Add file → Upload files**. ລາກ **ທຸກໄຟລ໌ ແລະ ໂຟນເດີ** ໃນແພັກເກັດນີ້ໃສ່ (`index.html`, `sw.js`, `manifest.webmanifest`, `icons`, `fonts`, `vendor`), ແລ້ວກົດ **Commit changes**.
4. ໄຟລ໌ `.nojekyll` ອາດຈະບໍ່ຖືກອັບໂຫຼດ ເພາະເປັນໄຟລ໌ເຊື່ອງ. ໃຫ້ກົດ **Add file → Create new file**, ພິມຊື່ `.nojekyll`, ປ່ອຍເນື້ອໃນຫວ່າງ ແລ້ວກົດ Commit.
5. ໄປທີ່ **Settings → Pages**. ຕັ້ງ **Source = Deploy from a branch**, **Branch = main**, ໂຟນເດີ **/ (root)** ແລ້ວກົດ Save.
6. ລໍຖ້າ 1–2 ນາທີ ແລ້ວເປີດ **`https://USERNAME.github.io/`**. ແອັບຈະຂຶ້ນມາ.

## ຂັ້ນທີ 2 — ຕິດຕັ້ງໃນໂທລະສັບ Android (ແບບ PWA)

1. ເປີດ `https://USERNAME.github.io/` ໃນ **Chrome** ເທິງໂທລະສັບ.
2. ກົດ **⋮** (ມຸມຂວາເທິງ) ແລ້ວກົດ **ຕິດຕັ້ງແອັບ (Install app)** ຫຼື **ເພີ່ມໄປໜ້າຈໍຫຼັກ**.
3. ໄອຄອນ "ການເງິນ" ຈະຂຶ້ນໃນໜ້າຈໍ. ເປີດແລ້ວໃຊ້ໄດ້ ເຖິງວ່າບໍ່ມີເນັດ.

ຖ້າໃຊ້ພຽງຄົນດຽວ, ເຮັດຮອດຂັ້ນນີ້ກໍ່ພຽງພໍ.

## ຂັ້ນທີ 3 — ສ້າງໄຟລ໌ APK ດ້ວຍ PWABuilder (ບໍ່ຕ້ອງຂຽນໂຄດ)

1. ເປີດ **https://www.pwabuilder.com** ໃນຄອມພິວເຕີ.
2. ໃສ່ທີ່ຢູ່ `https://USERNAME.github.io/` ແລ້ວກົດ **Start**.
3. ກົດ **Package for stores**, ເລືອກ **Android**, ແລ້ວກົດ **Generate Package**.
   - **Package ID:** ໃສ່ ເຊັ່ນ `io.github.username.kanngern` (ຕົວອັກສອນອັງກິດນ້ອຍ ແລະ ຈຸດ ເທົ່ານັ້ນ).
   - **App name:** `ການເງິນໂຄງການ`
   - **Signing key:** ເລືອກ **Create new**.
4. ດາວໂຫຼດໄຟລ໌ zip ທີ່ໄດ້ມາ. ໃນນັ້ນມີ:
   - `*.apk` — ໃຊ້ຕິດຕັ້ງໃສ່ໂທລະສັບໂດຍກົງ
   - `*.aab` — ໃຊ້ອັບໂຫຼດຂຶ້ນ Google Play
   - `signing.keystore` ແລະ `signing-key-info.txt` — ⚠️ **ເກັບໄວ້ໃຫ້ດີ ຢ່າໃຫ້ເສຍ.** ຖ້າເສຍ ຈະອັບເດດແອັບໃນ Play Store ບໍ່ໄດ້ອີກ.
   - `assetlinks.json`
5. **ເອົາແຖບທີ່ຢູ່ເວັບອອກຈາກແອັບ:** ໃນ repo ກົດ **Add file → Create new file**. ພິມຊື່ `.well-known/assetlinks.json`, ສຳເນົາເນື້ອໃນຈາກໄຟລ໌ `assetlinks.json` ທີ່ໄດ້ມາໃສ່, ແລ້ວກົດ Commit.
   > ຖ້າບໍ່ເຮັດຂັ້ນນີ້ ແອັບຍັງໃຊ້ໄດ້ ແຕ່ຈະມີແຖບທີ່ຢູ່ເວັບຢູ່ເທິງຈໍ.
6. **ຕິດຕັ້ງ APK:** ສົ່ງໄຟລ໌ `.apk` ເຂົ້າໂທລະສັບ (ຜ່ານ Telegram, Google Drive ຫຼື ສາຍ USB) ແລ້ວກົດເປີດ. ຖ້າໂທລະສັບຖາມ ໃຫ້ອະນຸຍາດ **"ຕິດຕັ້ງແອັບທີ່ບໍ່ຮູ້ຈັກ" (Install unknown apps)**.
7. **ລົງ Google Play (ບໍ່ບັງຄັບ):** ສະໝັກ Google Play Console (ຈ່າຍຄັ້ງດຽວ $25) ແລ້ວອັບໂຫຼດໄຟລ໌ `.aab`.

## ການອັບເດດແອັບ

1. ແກ້ໄຂໄຟລ໌ ແລ້ວອັບໂຫຼດທັບໃນ GitHub.
2. ເປີດ `sw.js` ແລ້ວປ່ຽນ `VERSION` ເປັນເລກໃໝ່ ເຊັ່ນ `fin-v1.0.1`. **ຕ້ອງປ່ຽນທຸກຄັ້ງ** ບໍ່ດັ່ງນັ້ນໂທລະສັບຈະບໍ່ໂຫຼດເວີຊັນໃໝ່.
3. ບໍ່ຕ້ອງສ້າງ APK ໃໝ່. ແອັບຈະດຶງເວີຊັນໃໝ່ເອງ ເມື່ອເປີດຕອນມີເນັດ ແລະ ຈະຂຶ້ນຂໍ້ຄວາມ "ມີເວີຊັນໃໝ່".

## ⚠️ ເລື່ອງຂໍ້ມູນ — ສຳຄັນ

- ຂໍ້ມູນ ແລະ ຮູບ ເກັບຢູ່ **ໃນໂທລະສັບເຄື່ອງນັ້ນເທົ່ານັ້ນ**. ຂໍ້ມູນບໍ່ sync ລະຫວ່າງເຄື່ອງ.
- ຂໍ້ມູນຈະຫາຍ ຖ້າ ລຶບແອັບ, ລ້າງຂໍ້ມູນ Chrome ຫຼື ເສຍໂທລະສັບ.
- ກົດ **💾 ສຳຮອງ** ເປັນປະຈຳ ແລ້ວເກັບໄຟລ໌ `.json` ໄວ້ Google Drive, Telegram ຫຼື ອີເມວ. ແອັບຈະເຕືອນ ຖ້າບໍ່ໄດ້ສຳຮອງເກີນ 7 ມື້.
- **ຍ້າຍໄປເຄື່ອງໃໝ່:** ຢູ່ເຄື່ອງເກົ່າກົດ 💾 ສຳຮອງ, ຢູ່ເຄື່ອງໃໝ່ກົດ 💾 ສຳຮອງ → ⬆️ ເລືອກໄຟລ໌ສຳຮອງ. ຂໍ້ມູນຈະມາຄົບ ລວມທັງຮູບ.

## ຍ້າຍຂໍ້ມູນຈາກເວີຊັນ claude.ai ມາແອັບນີ້

1. ໃນເວີຊັນ claude.ai: ຢູ່ໜ້າຫຼັກ ກົດ **📑 ລາຍງານ xlsx / csv**, ເລືອກ **ທັງໝົດ** ແລະ **Excel**, ແລ້ວດາວໂຫຼດ.
2. ໃນແອັບ: ຢູ່ໜ້າຫຼັກ ກົດ **📥 ນຳເຂົ້າ Excel** ແລ້ວເລືອກໄຟລ໌ນັ້ນ. ແອັບຈະເລືອກແຜ່ນ "ລາຍການ" ແລະ ສ້າງໂຄງການໃຫ້ອັດຕະໂນມັດ.
   > ຮູບພາບ ແລະ ສະກຸນເງິນຂອງໂຄງການ ຈະບໍ່ຖືກຍ້າຍມາ. ໃຫ້ຕັ້ງສະກຸນເງິນຄືນໃນ ✏️ ແກ້ໄຂໂຄງການ.
